## 2. Copywriting Guidelines

To ensure the portfolio content remains cohesive, readable, and highly optimized for conversions and search engines, the following structural guidelines must be followed:

### A. Case Studies Structure (Challenge-Solution-Result Layout)
Each project case study must be written using a structured 3-part layout to demonstrate business impact and technical depth:
1. **Challenge (El problema):** Define the exact friction or problem. E.g., *"Global brands couldn't advertise in virtual worlds due to financial friction and lack of transparency."*
2. **Solution (La solución):** Detail the precise technical resolution. E.g., *"AI, Web3, and Blockchain-based advertising architecture that removes intermediaries and makes every impression measurable."*
3. **Result/Metrics (El resultado):** Show quantifiable, verifiable metrics. E.g., *85% reduction in financial friction, 100% immutable traceability.*

### B. Header Hierarchy and Structure
To facilitate search indexing and semantic reading, keep the headers strictly structured:
* **H1:** Used exactly once per page (e.g. Page Title / Hero Main Title).
* **H2:** Section titles (e.g. `Proven Impact`, `Business Solutions`, `Thought Leadership`).
* **H3:** Project names or sub-sections (e.g. `VirtuadsAi`, `Orbit`, `ExEquine`, `El problema`, `La solución`).
* **H4/P:** Details and supporting copy.

### C. Image Accessibility (Alt Text Rules)
* Every image must have a descriptive, keyword-rich `alt` attribute.
* **Prohibited:** `alt="image"`, `alt="screenshot"`, or empty alt tags for critical images.
* **Examples of compliant alt texts:**
  - `alt="Wilfredo Caro - AI Multi-Agent Systems Architect and CEO at VirtuadsAi"`
  - `alt="Antigravity Monitor Desktop App interface showing AI agent hierarchy reconstruction"`
  - `alt="ExEquine decentralized registry smart contract deployment diagram"`

### B. Dynamic Canonical & JSON-LD Injection
* **Canonical URL & Social Graphs:** In `src/modules/i18n.js`, the active language `lang` is evaluated. The canonical, og:url, and twitter:url tags are updated dynamically (e.g. `https://wilfredocaro.com/?lang=es` for Spanish).
* **JSON-LD Schema Swapping:** In `src/modules/schema.js`, localized schemas of type `Person` are defined. On language update, the text content of `<script id="schema-ld">` is replaced with the stringified schema where any `<` character is escaped as `\\u003c` to prevent HTML breakout.

### C. Remediation Improvements (July 2026)
* **Content Security Policy (netlify.toml):** Whitelisted `https://w.soundcloud.com` inside the `frame-src` directive of Netlify's headers to enable the SoundCloud audio player without security warnings.
* **Schema.org Conformance (src/modules/schema.js & index.html):** Modified the `worksFor` structure for all 7 languages to remove nested `"jobTitle"` keys from inside `Organization` blocks to comply with strict Schema.org standards (Person job titles reside exclusively at the root level). Updated the initial static JSON-LD in `index.html` to align exactly with the English `en` schema.
* **HTML Breakout Prevention (src/modules/i18n.js):** Escaped the `<` character to `\\u003c` during dynamic JSON-LD injection to mitigate injection risks in pre-rendered environments.
* **WCAG 2.1 A/AA Focus Management (src/modules/cv-download.js & src/modules/service-modal.js):** Implemented programmatical focus placement on modal opening (moving focus to `#cv-name` / `#srv-name`), keyboard focus trapping via Tab/Shift+Tab looping, instant Escape key modal closure, and focus restoration to the original trigger element upon modal closure.
